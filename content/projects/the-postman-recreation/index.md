This project is a 3D animation reproduction of the animated promotional short [*The Postman*](https://www.youtube.com/watch?v=AfsxkcfZ6Oo). Developed collaboratively in Blender, the goal was to recreate the original piece's staging, timing, character posing, and scene layout.

**Project Overview:**

* **Role:** 3D Animator (Team Project).
* **Context:** 3D Animation Project.
* **Responsibilities:** Keyframe animation, character posing, shot staging, 3D asset and prop.
